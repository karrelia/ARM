# АРМ Теплооблік — прототип MVP

Вебдодаток для обліку відпущеної теплової енергії по будинках — заміна
Excel-книги `ЗБЛ новий сезон.xlsm` (VBA + Power Pivot). Прототип покриває
ядро щоденної роботи оператора: **введення показань → нормативний розрахунок →
архів**.

> **Дві реалізації в репозиторії:**
> - [`webapp/`](webapp/) — **клієнтський мобільний додаток** (без бекенду) у
>   дизайні/керуванні прикладу КП «Тепловодсервіс»: імпорт `.xlsm` у браузері,
>   IndexedDB, теми, дашборд/будинки/аналітика/ввід. Рекомендований варіант для
>   демонстрації. Запуск: `cd webapp && python3 -m http.server 8000`.
> - [`backend/`](backend/) + [`frontend/`](frontend/) — початковий MVP на
>   FastAPI + React/Vite (нижче).

Уся бізнес-логіка перенесена 1:1 з VBA (`UserForm1`, `Module1`) у
[`backend/app/calculations.py`](backend/app/calculations.py) і покрита тестами.

## Архітектура

```
frontend (React + TypeScript + Vite)
        │  REST /api
backend  (FastAPI + SQLAlchemy)
        │
   БД (SQLite за замовч.; PostgreSQL через DATABASE_URL)
```

| Сутність | Походження з книги |
|----------|--------------------|
| `House`    | `Довідники!TabAbon` + `TabTN` (теплове навантаження) |
| `Reading`  | `Архів!TabBaza` (історія показань) |
| `Boiler`   | довідник «Котельні» |

## Ключові формули (з VBA)

```
Обсяг ТЕ, Гкал = (поточний − попередній показник) × коеф_одиниці
                 (МВт×0.86, ГДж×0.2388, кВт×0.00086, Гкал×1)

Q розрахункове = (ТН / 1000) × тривалість × частка × (18 − t_сер) / 41
Різниця = факт − норматив;   % = Різниця / норматив × 100
```

## Запуск backend

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.seed                  # демо-дані (5 будинків, 3 котельні)
uvicorn app.main:app --reload       # http://localhost:8000  (Swagger: /docs)
```

Запуск тестів формул:

```bash
cd backend && pytest
```

## Запуск frontend

```bash
cd frontend
npm install
npm run dev                         # http://localhost:5173
```

Dev-сервер Vite проксіює `/api` на `http://localhost:8000`.

## Імпорт реальних даних з .xlsm (Етап 0)

```bash
cd backend && source .venv/bin/activate
python import_xlsm.py "/шлях/до/ЗБЛ новий сезон.xlsm"
```

Скрипт читає `TabAbon`, `TabTN`, `TabBaza` і завантажує будинки, котельні та
історію показань у БД.

## Що реалізовано в MVP

- ✅ Довідник будинків/абонентів (з котельнею, одиницями, тепловим навантаженням)
- ✅ Форма введення показань з автозаповненням попереднього показника
- ✅ Живий нормативний розрахунок (факт / норматив / різниця / %)
- ✅ Валідація (поточний показник не може бути меншим за попередній)
- ✅ Архів показань по будинку
- ✅ Імпорт з реального `.xlsm`
- ✅ Тести бізнес-логіки
