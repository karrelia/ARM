ОБРОБКА 1С «Завантаження показників Теплооблік»
================================================

Що робить
---------
Бере файл «Повний список» із застосунку (Огляд → Для 1С → Повний список) і
створює в 1С документи за міткою «Метод 1С» кожного приладу:
  Акт      — Акт зняття показань теплолічильника (один на особовий, усі його
             лічильники; з водою, наробітком, простоєм, температурами,
             витратою теплоносія й миттєвою потужністю)
  Опалення — Ввід показань приладів (опалення), один на особовий
  Ввід     — Ввід показань приладів обліку, один на особовий
  Акт+Ввід — обидва документи

Перш ніж щось створювати, обробка ПЕРЕВІРЯЄ кожен рядок і показує:
  червоним   — помилки, документ НЕ створиться, поки не виправите:
               не знайдено особовий; не знайдено прилад №… (і які прилади
               стоять на особовому в 1С — якщо прилад замінили, оформіть
               заміну в 1С); не вказано метод 1С
  помаранчевим — попередження (за замовчуванням без галочки):
               показник менший за попередній у 1С; документ за цей місяць
               уже є; прилад у 1С встановлено на іншому особовому
  «OK»       — готово, з галочкою
Галочка «Показати лише помилки» залишає в таблиці тільки те, що треба виправити.
Виправили в 1С → «Перевірити ще раз».


Як зібрати .epf (один раз)
--------------------------
Так само, як інші ваші обробки, — скриптом:
  тека  D:\ОБРОБКА 1С\ЗавантаженняПоказниківТеплооблік\
  на ПК, де є Конфігуратор (1cv8.exe), запустіть  build-epf.cmd
  (запитає базу 192.168.1.165\tvs_abon, логін і пароль) — поруч з'явиться
  ЗавантаженняПоказниківТеплооблік.epf. Подробиці — ЧИТАЙ.md у тій теці.

Вихідники (src) у ту теку кладе генератор із проєкту:
  python 1c\build_epf_src.py "D:\ОБРОБКА 1С\ЗавантаженняПоказниківТеплооблік\src"
Без аргументу — у 1c\epf (тека в .gitignore).


Як користуватися
----------------
1. У застосунку: Огляд → оберіть місяць → «Для 1С» → «Повний список».
2. У 1С: «Файл» → «Відкрити» → D:\ОБРОБКА 1С\ЗавантаженняПоказниківТеплооблік\ЗавантаженняПоказниківТеплооблік.epf.
3. Вкажіть файл → «Прочитати й перевірити». Звітний місяць підставиться сам
   (за датами зняття у файлі) — перевірте його.
4. Виправте червоні рядки (у 1С чи в застосунку) → «Перевірити ще раз».
5. «Створити документи». Галочка «Проводити документи» — увімкнена.
   Документи створюються лише для рядків із галочкою; у колонці «Документ» —
   посилання на створений документ. Повторно той самий рядок не створюється.

Організація документів — з кодом 000000001 (як у ваших формах «Загрузка из Excel»).

Для розробника: модуль форми — 1c\src\Module.bsl; після змін
  python 1c\build_epf_src.py   — перегенерує 1c\epf.
